README

Ceci est un programme qui crée une base de données SQLite puis utilise des requetes http pour la remplir à partir d'une API. 
J'utilise une pagination pour télécharger 10000 enregistrements a la fois.

This program creates an SQLite database and uses http requests to fill it in with data from a public API.
I used pagination to access the records 10000 at a time.
