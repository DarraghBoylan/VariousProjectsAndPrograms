README

This is a simple to-do list that's built on the M-V-C model.
You can create, edit and delete items from the list.
Your tasks are saved in an SQL database.

Ceci est une liste de tâches construite sur le modèle M-V-C.
Vous pouvez créer, editer et supprimer des tâches.
Les tâches sont sauvegardés dans une base de données SQL.
