README

Ceci est un programme qui triangule la localisation des stations Vlib à Paris, puis calcule le meilleur moyen de les alimenter en utilisant l'algorithme de Kruskal. 
Il analyse ensuite leur répartition avec l'algorithme de Voronoy pour trouver lesquels sont le moins bien désservis.

This program triangulates the location of the Vlib stations in Paris, then calculates the best way to connect them in a power grid with Kruskal's algorithm. 
It then analyses their distribution and proximity with each other using Voronoy's algorithm to find which ones are under-served.
